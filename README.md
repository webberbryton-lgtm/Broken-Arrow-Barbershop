# Broken Arrow Barbershop — Shopify Theme

Custom Shopify theme built on **Horizon v4.2.0** (Shopify's official theme).
Connected to the store through Shopify's GitHub integration: pushes to `main` sync to the theme, and theme-editor changes commit back here.

Custom Broken Arrow files are prefixed `ba-` (e.g. `sections/ba-hero.liquid`) so they stay separate from Horizon's own files.
